The `OffCanvas.tsx` component is a React wrapper for the UIkit [Off-canvas component](https://getuikit.com/docs/offcanvas). It bridges React's declarative state with UIkit's imperative JavaScript API.

Key Responsibilities:

1. UIkit Integration: It uses `UIkit.offcanvas(el)` to initialize the component and calls `.show()` or `.hide()` based on the open prop.
2. Event Synchronization: It listens for UIkit's native `hidden` event and triggers the `onClose` callback, ensuring the React state stays in sync with the UI (e.g., if a user clicks the overlay to close).
3. DOM Management: It uses `createPortal` to render the off-canvas element at the end of `document.body`, which is a requirement for UIkit off-canvas components to avoid CSS nesting issues.
4. Configuration: It passes settings like `mode`, `overlay`, and `flip` to UIkit via the `data-uk-offcanvas` attribute.
5. Context Provider: It wraps its children in `OffCanvasContext.Provider`, allowing sub-components (like `OffCanvasBar`) to access the `open` state.

Props:

- `open`: Boolean controlling visibility.
- `onClose`: Callback for when the off-canvas is closed (either via code or user interaction).
- `overlay`: Whether to dim the background.
- `flip`: If true, the off-canvas appears from the right.
- `mode`: Transition style (`slide`, `push`, `reveal`, or `none`).
