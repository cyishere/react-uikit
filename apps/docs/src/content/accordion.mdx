## Basic Usage

<BasicUsage client:load>
  ```jsx
  <Accordion.Root>
    <Accordion.Item>
      <Accordion.Trigger>Item 1</Accordion.Trigger>
      <Accordion.Panel>
        <p>
          Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt
          ut labore et dolore magna aliqua.
        </p>
      </Accordion.Panel>
    </Accordion.Item>
    <Accordion.Item>
      <Accordion.Trigger>Item 2</Accordion.Trigger>
      <Accordion.Panel>
        <p>
          Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt
          ut labore et dolore magna aliqua.
        </p>
      </Accordion.Panel>
    </Accordion.Item>
    <Accordion.Item>
      <Accordion.Trigger>Item 3</Accordion.Trigger>
      <Accordion.Panel>
        <p>
          Lorem ipsum dolor sit amet, consectetur adipiscing elit, sed do eiusmod tempor incididunt
          ut labore et dolore magna aliqua.
        </p>
      </Accordion.Panel>
    </Accordion.Item>
  </Accordion.Root>
  ```
</BasicUsage>

We can set default open panel and icon for an accordion by set an array to `defaultOpen` and set `showIcon` to `true`.

<IconUsage client:load>
  ```jsx
  <Accordion.Root defaultOpen={[1]} showIcon>
    {/* ... */}
  </Accordion.Root>
  ```
</IconUsage>
