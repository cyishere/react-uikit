## Basic Usage

UIkit provides robust styling for alerts. If you only need the visual styles and want to manage the alert's lifecycle yourself (for example, showing a success message for 2 seconds after a form submission), you can apply the `.uk-alert` class and its modifiers to any `div`.

```jsx
// Pure CSS usage - managed by your own state
{
  isVisible && <div className="uk-alert uk-alert-success">Message sent successfully!</div>;
}
```

Available modifier classes include `.uk-alert-primary`, `.uk-alert-success`, `.uk-alert-warning`, and `.uk-alert-danger`.

## Alert Component

While you can use CSS classes for styling, the `Alert` component provided by `react-uikit` is the preferred choice when you need the **built-in close functionality**. It automatically handles:

- Applying the base `.uk-alert` CSS class.
- The close button placement and styling.
- UIkit's fade-out animations.
- Removing the element from the DOM after it closes.
- Lifecycle events (`onBeforeHide`, `onHide`).

Just like with a standard `div`, you can use the `className` prop to apply modifier classes such as `.uk-alert-primary` or `.uk-alert-danger`.

## Custom Close Button

By default, the `Alert` component renders a [Close](/close) button. You can disable this by setting `showCloseButton={false}`. To use your own close button, provide a CSS selector to `selClose` that matches your custom element.

```jsx
<Alert showCloseButton={false} selClose=".my-custom-close">
  <p>Custom alert with a text close button.</p>
  <button className="my-custom-close" type="button">
    Dismiss
  </button>
</Alert>
```

## API Reference

The `Alert` component is a standalone component where all behaviors are encapsulated within `<Alert />`. It renders as a `div` element and accepts all standard HTML `div` attributes.

| Prop            | Type                     | Default           | Description                                                                        |
| --------------- | ------------------------ | ----------------- | ---------------------------------------------------------------------------------- |
| showCloseButton | `boolean`                | `true`            | Whether to show the default close button.                                          |
| animation       | `boolean`                | `true`            | Whether to animate the alert when closing.                                         |
| duration        | `number`                 | `150`             | Base duration of the close animation in milliseconds.                              |
| selClose        | `string`                 | `.uk-alert-close` | CSS selector for the close button, used to customize the close trigger.            |
| onBeforeHide    | `(event: Event) => void` | `undefined`       | Fires a callback function just before the Alert starts its closing animation.      |
| onHide          | `(event: Event) => void` | `undefined`       | Fires a callback function once the Alert has been completely removed from the DOM. |
