import CloseButton from '@/components/Alert/CloseButton.tsx';

## Usage

For purely using UIkit's Alert style, apply the CSS class `.uk-alert` (required) or combine it with `.uk-alert-primary`, `.uk-alert-success`, `.uk-alert-warning` and `.uk-alert-danger`.

```html
<div class="uk-alert"></div>
<div class="uk-alert uk-alert-primary"></div>
<div class="uk-alert uk-alert-success"></div>
<div class="uk-alert uk-alert-warning"></div>
<div class="uk-alert uk-alert-danger"></div>
```

## Close button

The `Alert` component of `react-uikit` builds in the **close button**.

<CloseButton client:load>
  ```jsx
  <Alert>
    Eu eu cillum duis in officia aliquip enim qui sunt officia eu pariatur nostrud elit esse ut.
  </Alert>
  ```
</CloseButton>
