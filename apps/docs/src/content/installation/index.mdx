Install the packages with your prefered package manager.

```bash
npm i react-uikit uikit

# or
pnpm add react-uikit uikit

# or
yarn add react-uikit uikit
```

## Usage

Styles are not automatically injected. You must import the stylesheet in your app entry point:

```jsx
import 'uikit/dist/css/uikit.min.css';
import 'react-uikit/styles.css';
```

<span class="uk-label">Note</span> `react-uikit/styles.css` is only needed by `Accordion` and `Switcher` related components. If you don't use these components, you don't need to import the stylesheet.

If you want to use a custom theme, see the [Themes](/themes) guide.
