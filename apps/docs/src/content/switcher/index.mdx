## Usage

The `Switcher` component consist of a number of toggles and their related content items. It uses a compound structure to co-response to UIkit Switcher.

<span class="uk-label">Note</span> In UIkit's Switcher component, it uses `a` tag with `href="#"` inside the `li` element as the trigger, but in `react-uikit`, we replace `a` with `button`.

- `<Switcher.Root>` equivalent to the wrapper with `uk-switcher` attribute—`<div uk-switcher>`.
- `<Switcher.List>` equivalent to the `ul` inside the wrapper `div`.
- `<Switcher.Trigger>` equivalent to each trigger item inside `ul`, co-responding to `<li><a href="#" /></li>`.
- `<Switcher.Container>` equivalent to the wrapper `div` for the content panels.
- `<Switcher.Panel>` equivalent to the `div` which contains the actual content.

```jsx
<Switcher.Root>
  <Switcher.List className="uk-subnav uk-subnav-pill">
    <Switcher.Trigger>Tab 1</Switcher.Trigger>
    <Switcher.Trigger>Tab 2</Switcher.Trigger>
  </Switcher.List>
  <Switcher.Container>
    <Switcher.Panel>Content of panel 1</Switcher.Panel>
    <Switcher.Panel>Content of panel 2</Switcher.Panel>
  </Switcher.Container>
</Switcher.Root>
```

Same as UIkit Switcher, this component are styled through other components, such as the example below, it uses the _Subnav component_.

## Navigation Controlls

In some cases you want to switch to another content section from within the active content. This is possible using the `Switcher.Item` component. To target the items, you need set the `to` prop with the number of the respective content items. The order number of the content items starts with `0`.

Setting `to` prop to `next` and `previous` will switch to the adjacent items.

`Switcher.Item` is an unstyled `button` element, you can add UIkit's text or other CSS classes to style it as needed.

```jsx
<Switcher.Item className="uk-text-primary" to={2}>
  Go to the third panel
</Switcher.Item>
```

## Connect Multiple Containers

It is also possible to connect multiple content containers. Just add extra `Switcher.Container` blocks.

```jsx
<Switcher.Root>
  <Switcher.List>...</Switcher.List>
  
  {/* These are the containers of the content items */}
  <Switcher.Container>...</Switcher.Container>

  <Switcher.Container>...</Switcher.Container>
</Switcher.Root>
```

## Animations

You can apply all animation CSS classes from [UIkit's Animation component](https://getuikit.com/docs/animation) to switcher items. To do so, set an `animation` prop to `Switcher.Root`.

```jsx
<Switcher.Root animation="uk-animation-fade">...</Switcher.Root>
```

<Animations />

### Multiple Animations

You can also apply multiple animations by using two animation CSS classes. That way you can add different **in** and **out** animations. The two CSS classes need to be separated by comma.

```jsx
<Switcher.Root
  animation="uk-animation-slide-left-medium, uk-animation-slide-right-medium"
>
  ...
</Switcher.Root>
```

## Switcher and Subnav

The switcher is easily applied to the Subnav component. To do so, add Subnav related CSS classes to `Switcher.List`.

```jsx
<Switcher.List className="uk-subnav uk-subnav-pill">...</Switcher.List>
```

## Switcher and Tab

To use UIkit's Tab style, add `uk-tab` CSS class to `Switcher.List`.

```jsx
<Switcher.List className="uk-tab">...</Switcher.List>
```

<Tab />

### Verticle Tabs

Use the [Grid component](/grid) and UIkit's width CSS classes to display content correctly with a verticle tabbed navigation.

```jsx
<Switcher.Root>
  <Grid>
    <div className="uk-width-auto">
      <Switcher.List className="uk-tab uk-tab-left">...</Switcher.List>
    </div>
    <div className="uk-width-expand">
      <Switcher.Container>...</Switcher.Container>
    </div>
  </Grid>
</Switcher.Root>
```

## Switcher and Button

In `react-uikit`, the Switcher's trigger by default is a unstyled `button` element. So, you could use UIkit's button CSS classes to style it.

```jsx
<Switcher.Trigger className="uk-button uk-button-default">...</Switcher.Trigger>
```

By default, `Switcher.List > Switcher.Trigger` is an unorder list: `ul > li > button`. If you don't combine Switcher with Tab or Subnav CSS classes, you need to add `.uk-list` to remove the default list style from browser, and add `.uk-flex` or any other CSS rules to style it.


```jsx
<Switcher.List className="uk-list uk-flex">
  <Switcher.Trigger className="uk-button uk-button-default">Item 1</Switcher.Trigger>
  <Switcher.Trigger className="uk-button uk-button-default">Item 2</Switcher.Trigger>
</Switcher.List>
```
