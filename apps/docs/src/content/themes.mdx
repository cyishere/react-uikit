---
title: 'Themes'
---

Use UIkit in a themable way by compiling UIkit SCSS yourself and overriding variables before the framework import.

## Why this approach

UIkit components like OffCanvas are styled by generated CSS rules, not only by runtime CSS variables. For example, OffCanvas background/text colors are controlled by SCSS variables at build time.

Use theming when you want consistent component-level color behavior across the whole system.

## 1) Install Sass in docs

```bash
pnpm --filter docs add -D sass
```

## 2) Create a theme entry file

Create `apps/docs/src/styles/theme.scss`:

```scss
@import 'uikit/src/scss/variables-theme.scss';
@import 'uikit/src/scss/mixins-theme.scss';

$offcanvas-bar-background: #fff;
$offcanvas-bar-color-mode: dark;

@import 'uikit/src/scss/uikit-theme.scss';
```

Import order matters:

1. UIkit theme variables
2. UIkit theme mixins
3. Your variable overrides
4. UIkit theme bundle

## 3) Use your compiled theme in the layout

In `apps/docs/src/layouts/Base.astro`, import your SCSS theme instead of prebuilt UIkit CSS:

```ts
import '../styles/theme.scss';
```

## 4) Suppress Sass `@import` deprecation warnings (optional)

UIkit 3 still uses `@import` internally, so Sass prints deprecation warnings.

Add this in `apps/docs/astro.config.mjs`:

```js
import { defineConfig } from 'astro/config';
import mdx from '@astrojs/mdx';
import react from '@astrojs/react';

export default defineConfig({
  integrations: [react(), mdx()],
  vite: {
    css: {
      preprocessorOptions: {
        scss: {
          quietDeps: true,
          silenceDeprecations: ['import']
        }
      }
    }
  }
});
```

## 5) Where to find theme variables

UIkit SCSS variables live in:

- `uikit/src/scss/variables-theme.scss` (theme defaults)
- `uikit/src/scss/variables.scss` (core defaults)

Search for component tokens such as `offcanvas` and override only what you need.

## Notes

- Prefer SCSS variable overrides for system-wide theming.
- Use local CSS overrides only for one-off demos or temporary experiments.
