`react-uikit` is a React component library that integrates with [UIkit](https://getuikit.com). It uses UIkit CSS as the primary visual layer and follows a strict ownership model that defines, for every component, whether React or UIkit JS controls behavior and state.

It supports _React 19 and newer_, and works with UIkit 3.

<Info variant="primary">
#### Heads Up

`react-uikit` is in early development (the `0.x` series). The component set is still growing and APIs may change between minor versions until a `1.0` release. Feedback and contributions are welcome on [GitHub](https://github.com/cyishere/react-uikit).
</Info>

## Design principles

### A deliberate boundary between CSS and JS

UIkit ships both a CSS layer and an optional JavaScript layer. Many UIkit components are purely CSS-driven and need no JavaScript at all — `Button`, `Badge`, `Label`, `Card`, and similar elements are complete with a class name. Wrapping these in React components would add indirection without solving a real problem.

`react-uikit` therefore does not provide React wrappers for CSS-only UIkit components.

### A documented ownership model

Every component in the library has a defined ownership row in the [Component Ownership Matrix](/component-ownership). The matrix records who owns styling, behavior, state, SSR safety, cleanup requirements, and the accessible pattern in use.

The two ownership patterns in use are:

- **React-owned** — React controls all state and behavior. UIkit CSS handles styling. UIkit JS never initializes on these nodes. `Accordion`, `Close`, `Icon`, and `Switcher` follow this pattern.
- **UIkit-JS-enhanced** — React renders the markup and UIkit JS augments it at runtime. `useIsomorphicLayoutEffect` initializes UIkit JS and cleans up on unmount. `Alert`, `OffCanvas` and `Grid` follow this pattern.

## Components

Each component has a dedicated page in the sidebar. A `cn` utility is also exported for composing UIkit class names conditionally.

## SSR

Components marked React-owned are safe to render on the server. Components that depend on UIkit JS (`Alert`, `Grid`) require client-side JavaScript but render their markup on the server without error; UIkit JS initializes after hydration via `useIsomorphicLayoutEffect`.
