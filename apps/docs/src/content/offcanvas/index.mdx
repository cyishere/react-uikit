## Usage

`OffCanvas` component has two parts: `OffCanvas.Root` and `OffCanvas.Bar`.

To toggle an off-canvas sidebar, you can use the [`Close` component](/close) and pass a function to its `onClick` prop.

<span class="uk-label">Note</span> Even with a `Close` button which wire-up with a close function, the `onClose` prop still needs to be set, so that the `Escape` key can close the off-canvas.

```jsx
<OffCanvas.Root open={isOpen} onClose={handleClose}>
  ...
</OffCanvas.Root>
```

### Overlay

To add an overlay, blanking out the page, set the `overlay` prop to `true` on `OffCanvas.Root`.

```jsx
<OffCanvas.Root overlay={true}>...</OffCanvas.Root>

{/* Or */}

<OffCanvas.Root overlay>...</OffCanvas.Root>
```

<Overlay />

## Flip Modifier

Set `flip` prop to `true` to `OffCanvas.Root` to adjust its alignment, so that it slides in from the right.

```jsx
<OffCanvas.Root flip={true}>...</OffCanvas.Root>

{/* Or */}

<OffCanvas.Root flip>...</OffCanvas.Root>
```

## Animation Mode

By default, the `OffCanvas` slides in. But you can actually choose between different animation modes for the OffCanvas' entrance. Just set one of the following mode to `mode` prop.

| Mode | Description |
|------|-------------|
| `slide` | The OffCanvas slides out and overlays the content. This is the default mode. |
| `push` | The OffCanvas slides out and pushes the site. |
| `reveal` | The OffCanvas slides out and reveals its content while pushing the site. |
| `none` | The OffCanvas appears and overlays the content without an animation. |

```jsx
<OffCanvas.Root mode="push">...</OffCanvas.Root>
```
