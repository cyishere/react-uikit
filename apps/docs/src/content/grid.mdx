```jsx

  <div>

    </Grid>
```

## Match Height

In `react-uikit`, for matching the height of grid cells, we need to apply `matchHeight` prop to `Grid`, by default height match apply to the direct children of `Grid`.

```jsx
<Grid matchHeight></Grid>
```

We can target explicit children by applying the target CSS class to `matchHeight`.

<Warning>
  Don't forget to put the dot `.` in front of the class name — `.uk-card-body`.
</Warning>

```jsx
<Grid matchHeight=".uk-card-body"></Grid>
```

<MatchHeight />

## Grid with Width

As in the original UIkit, `Grid` is also used in combination with the [Width component](https://getuikit.com/docs/width).

```jsx
<Grid>
  <div className="uk-width-auto@m"></div>
  <div className="uk-width-1-3@m"></div>
  <div className="uk-width-expand@m"></div>
</Grid>
```

### Child Width

If the grid columns are evenly split, you can add one of the `.uk-child-width-*` classes to `Grid` instead of adding a class to each of the items.

```jsx
<Grid className="uk-child-width-1-2@s uk-child-width-1-3@m"></Grid>
```

## Masonry

Set the `masonry` prop to either `"pack"` or `"next"` can create masonry layout for `Grid`.

| Masonry | Description |
|---------|-------------|
| `"pack"` | Sorts items into columns with the most room to make column heights as equal as possible. |
| `"next"` | Uses the natural item order. |

## Parallax

To move single columns of a `Grid` at different speeds while scrolling, add a number to `parallax` prop. The number sets the parallax translation in pixels.

```jsx
<Grid parallax={150}></Grid>
```

<Parallax />

To adjust the `Grid` parallax duration, set the `parallaxStart` and `parallaxEnd` props.

| Prop | Default | Description |
|------|---------|-------------|
| `parallaxStart` | `0` | Defines when the animation starts. |
| `parallaxEnd` | `0` | Defines when the animation ends. |

- For `parallaxStart`, the default value `0` means that the `Grid`'s top border and the viewport's bottom border intersect.
- For `parallaxEnd`, the default value `0` means that the `Grid`'s bottom border and the viewport's top border intersect.
- Values can be set in any dimension units, namely `vh`, `%` and `px`. The `%` unit relates to the `Grid`'s height.
- Both options allow basic mathematics operands, `+` and `-`.

```jsx
<Grid parallax={150} parallaxStart="100%" parallaxEnd="100%"></Grid>
```

To justify the `Grid` parallax if columns have different heights, for example in masonry grids, set value `true` to the `parallaxJustify` prop so all grid columns reach the bottom at the same time. Set `parallax` prop to `0` to only move the columns by their height until they justify. But of course an additional parallax translation value can be set as well.

```jsx
<Grid parallax={0} parallaxJustify={true} masonry="pack"></Grid>
```
