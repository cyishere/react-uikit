### Nested Grid

You can easily extend your grid layout with nested grids.

```jsx
<Grid>
  <div>
    <Grid>
      <div></div>
      <div></div>
    </Grid>
  </div>
  <div>
    <Grid>
      <div></div>
      <div></div>
    </Grid>
  </div>
</Grid>
```

<NestedGrid />

### Divider Modifier

Same as og UIkit, add the `.uk-grid-divider` class to separate grid cells with lines.

```jsx
<Grid className="uk-grid-divider"></Grid>
```
