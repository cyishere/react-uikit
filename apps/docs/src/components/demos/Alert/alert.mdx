## Usage

<BasicUsage client:load>
  ```jsx
  <Alert>
    Eu eu cillum duis in officia aliquip enim qui sunt officia eu pariatur nostrud elit esse ut.
  </Alert>
  ```
</BasicUsage>

## Close button

Add the [`Close`](/close) component with `.uk-alert-close` to function as close button for the Alert.

```jsx
<Alert>
  <Close className="uk-alert-close" />
</Alert>
```

<CloseButton client:load>
  ```jsx
  <Alert>
    <Close className="uk-alert-close" />
    Eu eu cillum duis in officia aliquip enim qui sunt officia eu pariatur nostrud elit esse ut
    officia sint cupidatat nostrud nulla do aliquip veniam in ut sint culpa.
  </Alert>
  ```
</CloseButton>
